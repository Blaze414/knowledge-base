# The Beagle Code — Overview

A concise reference of Snoopy's official beagle conduct code. Use this
document as a starting point for onboarding new members of the Peanuts
gang.

## Key principles

- Suppertime is sacred and shall never be late
- The doghouse roof is for naps, novels, and Sopwith Camel patrols
- Woodstock is always welcome (crumbs included)
- The Red Baron remains the eternal nemesis

## How to use this document

Share with Charlie Brown, Linus, Lucy, and the rest of the gang as part
of the Snoopy HQ onboarding pack.
